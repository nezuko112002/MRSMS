# MatReq — Construction Material Request System

A full-stack web application for managing material requests, approvals, warehouse releases, and cost tracking on construction projects.

---

## Stack

- **Framework** — Next.js 15 (App Router)
- **Language** — TypeScript
- **Styling** — Tailwind CSS v3 with glassmorphism UI
- **Backend / Auth / DB** — Supabase (PostgreSQL + Row Level Security)
- **State** — React hooks + Supabase real-time
- **Toasts** — react-hot-toast

---

## Quick Start

### 1. Create a Supabase project

Go to [supabase.com](https://supabase.com) → New Project.

### 2. Run the schema

In the **SQL Editor** of your Supabase project, open and run the full contents of:

```
supabase/schema.sql
```

This creates all tables, enums, RLS policies, auto-number triggers, indexes, and seeds 20 sample inventory items.

### 3. Clone & install

```bash
cd matreq
npm install
```

### 4. Environment variables

```bash
cp .env.local.example .env.local
```

Edit `.env.local` and fill in:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

Both values are in your Supabase project under **Settings → API**.

### 5. Create your first admin user

In your Supabase project:

1. Go to **Authentication → Users → Add User**
2. Enter email + password
3. After creation, run this in the SQL Editor:

```sql
update profiles set role = 'admin' where email = 'your@email.com';
```

### 6. Run the dev server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and sign in.

## User Roles

| Role | Access |
|---|---|
| **requestor** | Submit requests · View own requests · Confirm receipt |
| **manager** | Approve/reject requests · Adjust quantities · View costs |
| **warehouse** | Release materials · Manage inventory |
| **finance** | View all cost records and project spend |
| **admin** | Full access to all pages + user management |

### Creating more users

Option A — Supabase Dashboard → Authentication → Add User, then set role in profiles table via SQL.

Option B — Enable the Supabase service role key and use the Invite User button on the `/admin` page.

## Workflow

```
Requestor submits request (multi-item)
        ↓
Manager reviews each item, adjusts qty, approve/reject
        ↓
Warehouse verifies stock, sets release qty, deducts inventory → issues MRS slip
        ↓
Requestor confirms receipt (qty + condition) → cost records created
        ↓
Finance views cost records by project
```

### Request number format

- Material Requests: `MR-2025-0001`
- Release Slips: `MRS-2025-0001`

Both auto-generated by database triggers.

## Customisation tips for Cursor

- **Add more inventory categories** — edit `DEPARTMENTS` and `UNITS` in `src/lib/utils.ts`
- **Change brand color** — edit `brand` in `tailwind.config.ts` (currently indigo)
- **Add email notifications** — hook into `approval_history` inserts via Supabase Edge Functions
- **Print/export** — the `window.print()` call on request detail is a starting point; add a print stylesheet
- **Real-time updates** — Supabase channels work out of the box; subscribe to `material_requests` changes in the dashboard
- **File attachments** — Supabase Storage + add an `attachments` table linked to requests
